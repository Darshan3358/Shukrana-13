# Shukrana-13

Next-generation decentralized Web3 token presale platform built on the Solana ecosystem with AI agents, automated trading tools, and prediction markets.

## Architecture (MERN Fullstack)
- **Frontend**: React 18, Vite 6, Tailwind CSS, Lucide Icons, Glassmorphism UI
- **Backend**: Node.js, Express, MongoDB
- **Deployment**: Unified Vercel serverless deployment (`vercel.json`)

## Run Locally

```bash
# Install root dependencies
npm install

# Install client dependencies
cd client && npm install && cd ..

# Start backend
npm run server

# Start frontend
npm run client
```
